# Nguồn dữ liệu HireUS Tools

Quy tắc được duy trì tại
[documents/.agents/rules/source-of-truth.md](../../documents/.agents/rules/source-of-truth.md).
Đọc file đó trước khi dùng thông tin nghiệp vụ. Không duy trì thêm một bản sao quy tắc ở workspace.

Dùng [project-navigator](../skills/project-navigator/SKILL.md) để tìm nguồn theo
nội dung cần làm. Code và kết quả kiểm tra trong repo liên quan là bằng chứng
triển khai; kế hoạch không xác nhận tính năng đã hoàn thành.
